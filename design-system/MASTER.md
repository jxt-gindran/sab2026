# MASTER Design System: SAB 2026 (Modern Revamp)

## 🎨 Color Palette
- **Primary Text**: Midnight Navy (#002B49) - Used for all primary headlines and body text.
- **Background**: Absolute White (#FFFFFF) - Emphasizing clean, medical whitespace.
- **Action/CTA**: Urgent Coral (#FF6F00) - For critical buttons like "Donate".
- **Accent**: Electric Cyan (#00AEEF) - For icons, horizontal lines, and highlights.
- **Subtle**: Slate Gray (#F8FAFC) - For section backgrounds and input fields.

## 🔡 Typography
- **Headings**: Inter (Bold/ExtraBold/Black) - Tracking: -0.05em. 
- **Body**: Inter (Regular/Medium) - Line Height: 1.6.

## ✨ Effects & UI Patterns
- **Cards**: Bento Box Grid for Riders. `rounded-[2rem]` corners.
- **Gradients**: Subtle background glows using Cyan and Coral (low opacity).
- **Animation**: `animate-fade-in` for text, `animate-float` (bounce) for glass cards.
- **Glassmorphism**: `backdrop-blur-xl` for overlays and sticky navigation.

## 🚀 UX Strategy
1. **Humanity First**: Use real faces (Surgeons, Children, Riders). Emotional storytelling over dry stats.
2. **Frictionless Giving**: Progressive multi-step donation form to avoid overwhelm.
3. **Rider Recognition**: Treat riders as "Champions" with individual goal tracking.

## 🛠️ Components
- **Navbar**: Floating White Glassmorphic bar.
- **Hero**: Story-driven Split Layout.
- **RiderCard**: Bento card with progress bar and photo.
- **DonationFlow**: Multi-step wizard with payment method selection.
